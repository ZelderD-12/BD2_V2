# 🗄️ BACKUP y RESTAURACION de la BD (ClinicaF + ClinicaF_DW)

## 📤 EXPORTAR / HACER BACKUP (ambas BD)

# Paso 1: Abrir terminal en la raiz del proyecto
cd C:\Users\tobia\Desktop\Programas\Docker\BD PF

# Paso 2: Exportar (se guarda en sql/export/)
make db-export

# Crea 2 archivos en sql/export/:
#   ClinicaF_20260530_123456.bak
#   ClinicaF_DW_20260530_123456.bak


## 📥 IMPORTAR / RESTAURAR (ambas BD)

### Opcion 1: Usar make
# 1. Pone los .bak en:   sql/import/
#    - ClinicaF_xxx.bak
#    - ClinicaF_DW_xxx.bak
# 2. Ejecuta:
make db-import


### Opcion 2: Restaurar desde Downloads
# Pone ClinicaF.bak y ClinicaF_DW.bak en Descargas y ejecuta:
make db-import-downloads


### Opcion 3: Manual
# 1. Copiar backups al contenedor:
docker cp C:\Users\tobia\Desktop\Programas\Docker\BD PF\sql\import\ClinicaF.bak clinica_sqlserver:/var/opt/mssql/backup/restore_f.bak
docker cp C:\Users\tobia\Desktop\Programas\Docker\BD PF\sql\import\ClinicaF_DW.bak clinica_sqlserver:/var/opt/mssql/backup/restore_dw.bak

# 2. Restaurar:
docker exec clinica_sqlserver /opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P "ClinicaDBgrupo3#" -C -Q "RESTORE DATABASE [ClinicaF] FROM DISK = N'/var/opt/mssql/backup/restore_f.bak' WITH REPLACE, RECOVERY"
docker exec clinica_sqlserver /opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P "ClinicaDBgrupo3#" -C -Q "RESTORE DATABASE [ClinicaF_DW] FROM DISK = N'/var/opt/mssql/backup/restore_dw.bak' WITH REPLACE, RECOVERY"


## 📂 DONDE SE GUARDAN LOS BACKUPS

| Ubicacion                   | Descripcion                             |
|-----------------------------|-----------------------------------------|
| sql/export/                 | Backups de ClinicaF + ClinicaF_DW       |
| sql/import/                 | Aca se ponen los .bak para importar     |
| /var/opt/mssql/backup/      | Dentro del contenedor (temporal)        |


## ⚠️ NOTAS

- El make export guarda AMBAS bases de datos
- El make import busca ClinicaF*.bak y ClinicaF_DW*.bak en sql/import/
- Si solo tenes backup de ClinicaF, el DW se salta (sigue funcionando igual)
- La password del SA es: ClinicaDBgrupo3#
- Contenedor: clinica_sqlserver | Puerto: 1436
